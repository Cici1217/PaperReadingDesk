配置自己的本机 Codex

先在终端安装并登录，再保存和测试配置。

Codex 登录与查询
  1. 执行 codex login status 确认登录。
  2. 执行 codex，输入 /model 查看模型和推理强度。
  3. 输入 /status 确认当前选择。
Claude Code 安装与登录
npm install -g @anthropic-ai/claude-code
claude
  1. 首次运行会打开浏览器，按提示登录 Claude 账号。
  2. 如果未出现登录流程，请在 Claude Code 中输入 /login。
  3. 输入 /status 确认账号和模型。浏览器未打开时按 c 复制登录链接。

项目只保存命令、模型和测试状态，不保存账号、密码或令牌。

保存并测试成功后，可将该 CLI 设为当前论文 AI 后端。
